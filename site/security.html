Security, audit and contract status

Will & Key is live software with immutable contracts. It has substantial internal testing and no completed independent audit. Verify the evidence before using it.

Status checked 10 August 2026

Current risk status: deployed, internally reviewed and not independently audited. Do not use material value until the independent audit and full Base Sepolia lifecycle are complete.

Administrator powers

The administrator can pause creation of new vaults, change the global fee within the 1% hard cap, change the fee recipient and sweep only accounting surplus. Existing vaults retain their creation-time fee ceiling. The administrator cannot withdraw a user's locked balance or payout credit, change a beneficiary, cancel an owner withdrawal or block a valid claim settlement.

Administration has not yet been transferred from the deployer to the planned multisig/cold wallet. That transfer remains an operational recommendation.

Review and testing

  • 63 Hardhat contract tests pass.
  • A 14-step local watcher scenario passes, including delivery failures and claim backfill after an outage.
  • The internal adversarial report records fixed findings and unresolved design questions.
  • No independent third-party audit has been completed.
  • A real minimum-duration Base Sepolia claim lifecycle remains pending.

The contract is non-upgradeable. A serious contract finding requires a new deployment and a clearly communicated migration; it cannot be silently patched.

Website security

The interface is a static Cloudflare Pages deployment. Runtime dependencies are self-hosted. A restrictive Content Security Policy blocks third-party scripts, framing, objects, workers and unapproved network destinations. Chain-derived values are rendered with text nodes rather than HTML injection.

Report a vulnerability

Never publish working exploit details, a seed phrase or private key. Open a minimal GitHub issue asking for a private contact channel, identifying only the affected component and whether funds may face immediate risk. A report is not automatically eligible for a bounty; no bounty program is currently promised.
